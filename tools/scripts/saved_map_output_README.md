# LIORF Saved Map Output

This folder is generated by `liorf/save_map`.

## Structure

- `goereference.yaml`
  - Georeferencing data for map and trajectories.
  - Contains:
    - `gps_origin_enu` (`latitude`, `longitude`, `altitude`)
    - `T_enu_local` (`x`, `y`, `z`, `qw`, `qx`, `qy`, `qz`) - the optimized transform from local SLAM frame to ENU georeferenced frame at the time of GPS initialization.

- `save_summary.yaml`
  - Export metadata and counters.
  - Includes ROS save time, point counts, export flags, and destination metadata.

- `maps/`
  - `FullMap_local.pcd`
  - `SurfaceMap_local.pcd`
  - `FullMap_ENU.pcd` (only when ENU anchor is initialized)
  - `SurfaceMap_ENU.pcd` (only when ENU anchor is initialized)

- `trajectories/`
  - `trajectory_local.pcd`
  - `transformations_local.pcd`
  - `gps_raw_geodetic.csv` (if dense GPS export enabled)
  - `trajectory_keyframes_local.csv`
  - `trajectory_dense_local.csv` (if dense odometry export enabled)

## Notes

- Local frame files are always produced.
- ENU map files are produced only when `T_enu_local` has been initialized.
- CSV exports depend on runtime params:
  - `save_dense_gps_trajectory`
  - `save_dense_odom_trajectory`
